# SignalMoat brand assets

The icon shows an app at the centre (light square), ringed by a moat (teal
wavy ring), sending out an alert signal (amber arcs).

| File | Use |
|---|---|
| `signalmoat-icon.svg` | Master icon, any size from 64 px up |
| `signalmoat-icon-small.svg` | Simplified mark (plain ring, one arc, thicker lines) for 64 px and below |
| `signalmoat-icon-512.png`, `-256.png`, `-128.png` | Raster versions of the master icon (`-128` is the NuGet package icon) |
| `signalmoat-icon-64.png` | Small raster from the simplified mark |
| `favicon.ico`, `favicon-32.png`, `favicon-16.png` | Browser tab icons |

Colours: navy `#0E1B2C` (tile), teal `#35C2B0` (moat), amber `#F2A93B` (signal), ivory `#F3F0E8` (app).
